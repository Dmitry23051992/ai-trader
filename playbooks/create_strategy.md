# Playbook: Create Strategy

## Goal

Develop a new Freqtrade strategy.

---

## Workflow

1. Analyze existing strategies.

2. Determine whether a new strategy is required.

3. Generate strategy code.

4. Save strategy to:

freqtrade/user_data/strategies/

5. Validate Python syntax.

6. Explain strategy logic.

7. Recommend running a backtest.

---

## Expected Output

- Strategy file
- Summary
- Next recommended action
