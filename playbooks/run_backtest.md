# Playbook: Run Backtest

## Goal

Evaluate a strategy using historical market data.

---

## Workflow

1. Verify strategy exists.

2. Execute Docker backtest.

3. Collect results.

4. Save report.

5. Ask Backtest Analyst to review.

---

## Metrics

- Profit
- Profit Factor
- Sharpe
- Sortino
- Drawdown
- Win Rate
