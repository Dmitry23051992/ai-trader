# AI Trader Project

## Цель проекта

Создать автономную AI-систему для разработки, тестирования и оптимизации торговых стратегий Freqtrade.

---

## Структура

- freqtrade/ — официальный репозиторий Freqtrade.
- prompts/ — системные промпты агентов.
- memory/ — долговременная память проекта.
- docs/ — документация.
- scripts/ — автоматизация.
- configs/ — конфигурация.

---

## Правила

- Никогда не изменять код Freqtrade.
- Все стратегии создавать только в:

freqtrade/user_data/strategies

- Перед изменением существующей стратегии делать резервную копию.
- После создания стратегии проверять синтаксис.
- После изменения стратегии запускать backtest.
- Никогда не выполнять git push автоматически.

---

## Основной workflow

1. Создать стратегию.
2. Проверить синтаксис.
3. Запустить backtest.
4. Проанализировать результат.
5. Предложить улучшения.
6. Повторить цикл при необходимости.
