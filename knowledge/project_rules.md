# AI Quant Lab - Project Rules

## Mission

Develop, test and improve algorithmic trading strategies for Freqtrade.

---

## Never

- Modify the Freqtrade core.
- Delete user files.
- Overwrite strategies without confirmation.
- Execute destructive shell commands.

---

## Always

- Explain the execution plan.
- Check Python syntax.
- Recommend a backtest after code changes.
- Explain every important modification.
- Prefer reusable code.
- Use Git for version history.

---
